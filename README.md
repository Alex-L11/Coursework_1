# Анализ банковский операций

## Описание:
Это приложение для анализа транзакций, которые находятся в Excel-файле.

Функционал приложения:
* По каждой карте выдает: последние 4 цифры, общая сумма расходов, кэшбек
* Топ-5 транзакций по сумме платежа
* Курс валют
* Стоимость акций
* Выгодные категории повешенного кэшбека
* Отчеты по тратам по категории

## Установка:

1. Клонируйте репозиторий:
```shell
   git clone https://github.com/Alex-L11/Coursework_1.git
```

2. Установка зависимости:

```shell
   pip install -r requiremenys.txt
```

## Использование: 

1. Откройте PyCharm
2. В окне нажмите New project
3. В терминале введите команды из "Установка", пункты 1 и 2
